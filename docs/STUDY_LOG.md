1. **70% практика, 30% теория.** Видео и чтение без кода — впустую потраченное время.
2. **AI на учёбе — только для объяснений, не для генерации кода.** Иначе вырастешь вайбкодером без головы.
3. **Документацию читаем на английском.** Это твоё преимущество — используем.
4. **Каждый этап заканчивается мини-проектом без подсказок.** Это и есть проверка, что прошёл.
5. **Стабильность важнее скорости.** Лучше 10ч/неделю год, чем 25ч месяц и выгорание.
