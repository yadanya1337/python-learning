## День 1 (1.5ч) — Установка и настройка инструментов

### Что сделать:
1. **Установи Python 3.12 (или новее):** https://www.python.org/downloads/
   - При установке поставь галочку **"Add Python to PATH"** — это критично
   - Проверь в терминале: `python --version` и `pip --version`

2. **Настрой VS Code:**
   - Установи расширение **Python** (от Microsoft)
   - Установи расширение **Pylance**
   - Установи расширение **Black Formatter**

3. **Настрой Git и GitHub:**
   - Установи Git: https://git-scm.com/download/win
   - В терминале:
     ```
     git config --global user.name "Твоё имя"
     git config --global user.email "твой@email.com"
     ```
   - Сгенерируй SSH-ключ и добавь на GitHub. Гайд: https://docs.github.com/en/authentication/connecting-to-github-with-ssh
   - Создай новый репозиторий на GitHub: `python-learning` (можно private)

4. **Создай рабочую папку проекта:**
   ```
   D:\python-learning\  (или где удобно, главное путь без пробелов и кириллицы)
   ```
   Открой её в VS Code. Сделай первый коммит и пушни в GitHub.

## День 2 (1.5ч) — Виртуальное окружение и первый скрипт

### Теория (20 мин)
Прочитай: https://docs.python.org/3/tutorial/venv.html (раздел 12.1 и 12.2)

**Главное понять:** venv — это изолированное окружение Python для одного проекта. Ты ставишь библиотеки внутрь venv, и они не пересекаются с другими проектами. Это профессиональный стандарт. Без venv в реальной работе никто не работает.

### Практика (1ч 10мин)
1. В папке проекта создай venv:
   ```
   python -m venv venv
   ```

2. Активируй (Windows PowerShell):
   ```
   .\venv\Scripts\activate
   ```
   Если PowerShell ругается на политику — погугли "powershell execution policy venv" (это нормально, нужно один раз разрешить).

3. Установи библиотеку:
   ```
   pip install requests
   ```

4. Создай файл `day2_first_request.py` и напиши скрипт:
   - Делает GET-запрос на `https://api.github.com/users/torvalds`
   - Печатает имя пользователя, его публичные репозитории и подписчиков
   - Использует библиотеку `requests`

5. Создай файл `.gitignore` со строкой `venv/` (чтобы venv не попал в git).

6. Закоммить и пушни.

### ✅ Чек-лист дня:
- [ ] venv активирован, в начале строки терминала появилось `(venv)`
- [ ] Скрипт работает и выводит данные о Линусе Торвальдсе
- [ ] Понимаешь, зачем нужен venv (можешь объяснить вслух)

## День 3 (1.5ч) — Коллекции: список и словарь глубоко

### Теория (30 мин)
Прочитай: https://docs.python.org/3/tutorial/datastructures.html (разделы 5.1 — 5.5)

Особенно обрати внимание на:
- list comprehensions (`[x*2 for x in lst]`)
- методы списка: `.append()`, `.extend()`, `.pop()`, `.sort()`, `.sorted()` (разница!)
- dict comprehensions
- `.get()` у словаря и зачем он нужен

### Практика (1ч)
Создай файл `day3_collections.py`. Реши задачи **без гугления готового решения** (можно гуглить документацию):

1. Дан список чисел `nums = [3, 1, 4, 1, 5, 9, 2, 6, 5, 3, 5]`. Создай новый список, в котором только уникальные значения, отсортированные по возрастанию. (Подсказка: подумай про set.)

2. Дан список слов `words = ["apple", "banana", "apple", "cherry", "banana", "apple"]`. Создай словарь, где ключ — слово, значение — сколько раз оно встречается. (Не используй `Counter`, сделай руками через цикл и .get().)

3. Дан список словарей:
   ```python
   users = [
       {"name": "Alice", "age": 30},
       {"name": "Bob", "age": 25},
       {"name": "Charlie", "age": 35},
   ]
   ```
   Через list comprehension получи список имён только тех, кому больше 28 лет.

4. Используя dict comprehension, создай словарь, где ключи — числа от 1 до 10, а значения — их квадраты.

- [ ] Все 4 задачи решены без подглядывания готовых решений

## День 4 (1.5ч) — Функции глубоко

### Теория (30 мин)
Прочитай: https://docs.python.org/3/tutorial/controlflow.html (разделы 4.7 — 4.9)

Особенно:
- значения по умолчанию и их подвох с изменяемыми объектами
- `*args` и `**kwargs`
- что такое область видимости (LEGB rule — погугли коротко)

### Практика (1ч)
Создай файл `day4_functions.py`:

1. Напиши функцию `greet(name, greeting="Hello")` — принимает имя и приветствие (с дефолтом). Возвращает строку.

2. Напиши функцию `sum_all(*numbers)` — принимает любое количество чисел и возвращает их сумму.

3. Напиши функцию `make_user(**kwargs)` — принимает любые именованные аргументы и возвращает их как словарь, но с одним добавленным ключом `created_at` со значением текущей даты-времени (используй `datetime.now()`).

4. **Каверзная задача:** напиши функцию, которая принимает список строк и возвращает словарь, где ключ — первая буква строки, а значение — список всех строк, начинающихся на эту букву. Пример:
   ```python
   group_by_first_letter(["apple", "ant", "banana", "blue"])
   # → {"a": ["apple", "ant"], "b": ["banana", "blue"]}
   ```

## День 5 (1.5ч) — Работа с файлами + первый "проект"

### Теория (15 мин)
Прочитай: https://docs.python.org/3/tutorial/inputoutput.html (раздел 7.2)

Главное: что такое контекстный менеджер (`with open(...) as f:`), почему так делаем и почему НЕ делаем `f = open(...)` без with.

### Практика (1ч 15мин)
**Мини-проект: записная книжка контактов.**

Создай файл `day5_contacts.py`. Программа:
- При запуске показывает меню:
  ```
  1. Добавить контакт
  2. Показать все контакты
  3. Найти контакт по имени
  4. Удалить контакт
  5. Выйти
  ```

- При запуске программы — читает файл, при изменениях — перезаписывает
- Если файла нет — создаётся пустой список
- Контакт = словарь `{"name": "...", "phone": "...", "email": "..."}`

**Это первый твой настоящий мини-проект. Не торопись, делай аккуратно.**
